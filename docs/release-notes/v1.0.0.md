第一个可用版本：手机浏览器遥控 KOReader，走局域网，不需要蓝牙、不需要 root。

## 安装

下载下方的 `kremote.koplugin.zip`，解压出的 `kremote.koplugin` 文件夹整个放进 KOReader 的 `plugins/` 目录：

```
koreader/plugins/kremote.koplugin/
├── _meta.lua
├── main.lua
├── httpcore.lua
├── README.md
└── LICENSE
```

用 USB 或 scp 放好之后**重启 KOReader**，然后打开一本书，进菜单 **工具 → 手机遥控 → 启动遥控服务**，屏幕上会显示访问地址。

建议顺手勾上「打开 KOReader 时自动启动」，以后就不用每次点了。

> macOS 用户注意：用 Finder 拖到 Kindle（FAT32）会生成 `._*` 和 `.__*` 的 AppleDouble 文件，可能导致插件加载失败。装完在设备上清一下：
> `find /mnt/us/koreader/plugins/kremote.koplugin -name "._*" -delete`

## 功能

| 分组 | 能力 |
|---|---|
| 翻页 | 上一页 / 下一页（EPUB 和 PDF 都有效） |
| 章节 | 上一章 / 下一章 |
| 排版 | 字号 + / − |
| 显示 | 夜间模式、强制全刷 |
| 前光 | 0–24 档亮度滑杆，左右各一个步进键 |
| 状态 | 书名、作者、当前页/总页、百分比、电量、充电态、亮度档位，每 2 秒刷新 |
| 系统 | 重启 KOReader、退出 KOReader |

面板顶部的齿轮里有：夜间模式、强制全刷、字号 ±、重启、退出。点页面任意处收起。

## 已验证环境

- Kindle Basic 3（代号 `rex`），固件 5.18.1.1.1
- KOReader v2026.07.1，KPM 0.2.2
- 手机端用 Safari / Chrome 访问，面板为单屏无滚动布局

没有前光的机型也能用，亮度那一行会自动隐藏。

## 需要注意的几点

**Kindle 的 `iptables` INPUT 默认策略是 `DROP`**，出厂只放行 SSH 的 2222 端口。所以新端口的服务即使正常监听，外部也连不上，而设备本机 `127.0.0.1` 完全正常——很容易误判成"插件没加载"。插件会在启动服务时自动补一条放行规则，幂等，停止时只删自己加的那条。

**面板没有鉴权。** 同一 Wi-Fi 下任何人知道 IP 就能翻你的书。家里自己用没问题，公共网络下建议改成手动启动。

**不干预自动休眠。** Kindle 按自己的 30 分钟超时休眠省电；但手机发来的翻页、调亮度等**动作**会计为一次用户操作，重置计时，避免你正用手机翻页时设备中途睡过去。纯状态轮询不算，所以放下手机 30 分钟照样休眠。休眠后 Wi-Fi 会断，碰一下设备唤醒即可。

**书架上点翻页会返回 409。** 翻页、切章节、调字号都需要先打开一本书；夜间模式、全刷、亮度在书架界面照常可用。

## 已知限制

- 无鉴权，无 HTTPS
- 实时屏幕镜像做不了：e-ink 全刷每次 1 秒以上
- 依赖屏幕坐标的操作（选中文字、手写批注）无法可靠映射
- 音量、朗读不可用：设备没有扬声器

## 卸载

删掉 `kremote.koplugin` 整个目录，重启 KOReader。插件不写系统文件、不改配置。
